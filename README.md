# 月面速递 · Lunar Courier

当前版本 **1.4.0**。游戏首页的「更新公告」展示本版变更与历史公告，完整记录见 [CHANGELOG.md](CHANGELOG.md)。

背景音乐为原创程序合成配乐，包含和声铺底、旋律琶音、低音线及飞行鼓组。20 颗星球各有调性与节奏，实际速度越快，打击乐与旋律层越密；基地使用舒缓编排。首次主动操作后启用。操作指南提供音乐、引擎／音效独立音量与总静音；暂停及结算界面也可进入设置。暂停或离开页面会停止声音，继续飞行后恢复；声音偏好仅保留在当前页面。

一个可直接在浏览器游玩的 3D 星际悬浮艇游戏。在 20 颗架空星球的盘山公路上高速交付，穿过 6 座导航门、收集能量核心，再限时返航。20 条独立航线与三款悬浮艇全部开放。

山路分为连环山脊、环形天坑、双峰回旋、海岸长弯和高原阶梯五类，单程 7.0–14.4 公里。20 条路线的轮廓、高度、核心和障碍布置各有区别；机库支持搜索星球、航线与路线类型。新增极光幕、菌伞林、珊瑚树、盐晶阶柱、巨石拱门、磁悬岩、散热塔、彩色棱晶与星门。实际三维长度与仪表里程一致。速度越快，镜头视野越宽；减速时逐渐收回，速度线和引擎尾焰同步变化。

## 陨石与低重力航段

所有星球均包含动态环境。宁静天路有 2 处陨石落点、1 段低重力区；进阶山路有 3 处落点、2 段低重力区；极限山路有 4 处落点、2 段低重力区。

- **陨石落点**：红圈提前 2.6 秒预警，收缩圆环与仪表倒计时提示撞击时间。落地后的 1 秒内会产生冲击波，低空接触造成 22 点伤害。可横向绕开，也可把握时机跃升；成功在空中越过冲击波获得 180 分。灰色落点与撞击退去后的余辉不会伤害艇体。
- **低重力区**：紫色边线、入口光柱和雷达上的紫色航段标出范围。区内下落加速度由 17 降为 8，普通跃升可以达到约 7.5 米，腾空时间更长。腾空离开区域获得 200 分，但高空仍无法收集核心。
- 每处环境技巧奖励仅计一次；须在整个冲击波接触期间保持足够高度，脱离危险后才结算规避奖励，落入冲击波或漏门回退不会获得奖励。低重力滑翔按穿越出口瞬间的高度判定。成功交付可获得「踏星而行」「引力旅人」奖章，结算同时展示冲击波规避和滑翔次数。

陨石按实际飞行用时循环，倒计时与暂停不推进环境；重飞会重置时钟和奖励记录。个人幽灵与电脑对手采用相同的时间规则，电脑会评估连续障碍、巡逻机未来位置和落点的危险时间，再选择航向或跃升。

## 远征补给

在「任务机库」选择「远征补给」，驾驶一款飞船连续完成 20 站交付。沿途有 60 项可选委托：额外收集核心、高速从导航门中央通过，以及驶过加速带或跃过障碍。驾驶仪表实时显示目标、进度和完成状态。每站成功交付获得 **2 补给点**，每项达成的委托另获 **2 点**；未完成委托也能晋级，失败不发奖。

前 19 站交付后进入补给站，可自由购买升级或留下补给直接启航。每项最多两级，价格按每级计算：

| 升级 | 每级成本 | 每级效果 |
| --- | --- | --- |
| 矢量引擎 | 3 补给 | 巡航 +4 m/s、冲刺 +6 m/s |
| 回流电容 | 2 补给 | 每秒自动充能 +5 |
| 复合装甲 | 2 补给 | 装甲上限 +30 |
| 牵引磁场 | 3 补给 | 核心吸附半径 +1.2 m，跃升高空时无效 |

新赛段恢复全部装甲和能量，升级从起飞时生效；飞船下方的绿色圆环显示磁场吸附范围。失败或暂停后重飞会保留已购升级与余额，重置本站委托进度，已完成站点不会重复发奖。20 站结束后展示委托完成数、成功航程用时、补给收入与改装花费；用时只累计 20 次成功交付，不含失败与中途重飞。

远征成绩独立于普通幽灵和大奖赛。返回基地或刷新页面会结束远征，下一次从基础飞船与零补给开始；玩家进度只存在于当前页面内存。

## 月环大奖赛

在「任务机库」选择「月环大奖赛」，驾驶同一款飞船依次挑战从霁蓝星到引力星的 20 条山路。20 站合计 194.1 公里、120 座导航门。每站必须完成核心交付，才可晋级下一站。

迎光、钴蓝、余烬是三名电脑领航员，使用与你相同的飞船和驾驶规则。它们会收集核心、避让障碍，并按各自的路线和油门节奏完成航程。三艘不同颜色的投影和航线雷达显示对手位置，飞行仪表显示实时名次；投影互不碰撞。

- 每站按成功交付的飞行用时排名，第 1～4 名分别获得 **12 / 9 / 6 / 3 赛事积分**；同用时共享名次与积分。未完成交付不计分。
- 晋级后重新计时，装甲与能量补满；失败可重试本站，已完成赛段的积分保留。每站只结算一次。
- 总榜按积分排序，同分时依次比较完赛站数、累计用时。电脑未完赛的赛段按该站时限计入累计用时。
- 完成 20 站后，按总排名获得冠军、亚军、季军奖杯或完赛勋章。任务得分与赛事积分分别统计，成功航程仍可更新个人幽灵纪录。

赛事只存在于当前页面中。返回基地会结束当前赛事，刷新会清空所有纪录。暂停不会推进任何飞船；可在操作指南中关闭「航迹投影」，实时名次和积分仍会计算。

## 运行

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 http://localhost:5173 。需要支持 WebGL 2 的浏览器并开启硬件加速。触屏设备可使用同一局域网下的 Network 地址访问。

## 操作

| 操作 | 按键 |
| --- | --- |
| 加速 | 按住 W / ↑ |
| 左右避障 | A、D / ←、→ |
| 制动 | S / ↓ |
| 冲刺 | 空格，松开后自动充能 |
| 跃升 | F，消耗 18 能量，冷却 1.6 秒 |
| 暂停 / 继续 | Esc / P |
| 开始 | Enter / 点击开始飞行 |

屏幕驾驶按钮支持 Tab 聚焦，再用空格或 Enter 操作；持续动作需按住，跃升按一次触发。跃升按钮在空中、冷却中或能量不足时标记为不可用。

航向自动跟随环线，玩家负责速度和横向移动。蓝色核心增加分数、修复艇体并补充冲刺能量。岩石及航道边缘会损伤艇体；漏过导航门会退回门前并扣除 4 秒。切换标签页自动暂停。支持触屏、音效开关和两档画质；帧率偏低时会自动启用流畅模式，也可在操作指南中手动调整。

绿色加速带提供 1.8 秒免费加速和能量补充，驱动期间按住冲刺也会自动充能，跃升仍正常耗能；加速带效果结束后恢复手动冲刺的能量消耗。跃升可以越过岩石与移动巡逻机，但高空无法收集核心。须在整个接触期间保持足够高度，通过障碍后才获得空中避障奖励；中途落入障碍或漏门回退不会获奖。跳跃需要松开按键后才能再次触发。

连续收集每 3 枚核心提高一次得分倍率，最高 3 倍；漏收或碰撞会中断连收。普通过门 300 分，高速从门中央穿过得 500 分，空中避障得 120 分。成功返航另有时间和艇体奖励。

结算展示最高连收、精准过门、空中避障与任务奖章；无伤、快速返航、收集率和驾驶表现决定评级。每个航线与飞船组合的最佳得分、最快用时只保留在当前页面内存，刷新即清空。

## 幽灵挑战

自由速递模式下，首次成功返航后，再次驾驶同一款飞船挑战同一航线，会出现紫色个人幽灵，重现最快成功航程。幽灵不会碰撞或收集核心；只有更快的成功航程才会替换它，最高得分单独统计。可在任务机库或操作指南中关闭「航迹投影」，分段成绩仍会比较。

飞行仪表显示与幽灵的当前距离，以及最近一座导航门的累计时间差。每次过门另显示本区段的时间差；结算中的“分段飞行报告”可展开查看全部 6 座导航门与返航段，负值表示比起飞前的最快纪录更快。首航与失败航程也能查看已完成区段。

比较采用实际飞行用时：倒计时、暂停不计入；漏门会增加重新驶向导航门的飞行时间，并另外扣除剩余时限 4 秒。幽灵同步暂停，并按原航程重现漏门回退。轨迹只保存在当前页面内，刷新清空。

导航提示显示下一座门的对准方向；前方有可能相撞的岩石或巡逻机时，会提示距离和避让方式。巡逻机预警按当前速度估计相遇位置，仍需要观察实际航道并主动驾驶。


`dist/` 可以部署至静态网站托管服务。场景、模型和音效均由程序生成，无需外部素材服务；不会保存玩家运行状态。

## GitHub Pages

构建采用相对资源路径，同一份 `dist/` 可用于域名根目录或仓库子目录。GitHub Pages 需发布构建后的文件，直接从 `main` 根目录发布源码无法运行游戏。

1. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
2. 将包含工作流的提交推送至 `main`，会自动触发部署；之后也可在 **Actions → Verify and deploy Pages → Run workflow** 选择 `main` 手动运行。
3. 工作流使用 Node.js 22 执行 `npm ci`、测试和构建，通过后仅上传 `dist/` 并部署。部署成功后，从工作流的 `github-pages` 环境链接进入游戏。

本仓库的 Pages 地址为 https://hanazar-games.github.io/GPT6-Max-Test-Project-1/ 。Pull request 只运行测试与构建，不发布网站；手动选择非 `main` 分支也不会部署。`dist/` 不提交到 Git。

## 代码结构

技术：Three.js、Vite、原生 JavaScript、Web Audio。`src/missions.js` 定义任务、飞船和航线；`src/game.js` 是独立于渲染的固定步长模拟；`src/ghost.js` 管理有界轨迹采样、时间插值、分段比较和会话纪录；`src/pilots.js` 模拟电脑领航员，`src/cup.js` 管理赛事晋级、积分、实时排名和奖杯。测试覆盖驾驶规则、幽灵、赛事结算与同分排序，以及全部 60 种任务/飞船组合和 180 条电脑航程的连续通关。切换任务会释放旧场景资源，并复用渲染器；多艘投影共享几何体，使用独立材质。

`src/expedition.js` 管理远征委托、补给结算和晋级；`src/upgrades.js` 计算独立飞船配置；`src/expedition-ui.js` 展示委托与补给站。远征测试覆盖奖励去重、购买限制、失败重试、实际性能与吸附判定，以及各款飞船在 20 条航线上采用单项满级或全部满级升级的连续通关。

`src/environment.js` 定义环境时间表、重力、轨迹预测与陨石碰撞；`src/environment-view.js` 生成对应的三维场景。环境测试覆盖撞击时间边界、快速穿越与横向移动、暂停冻结、奖励去重、重试重置，以及连续障碍的电脑避让。

`src/route.js` 负责实际长度的山路、路面倾斜与随速度变化的镜头视野；`src/planet-view.js`、`src/landmarks.js` 和 `src/craft-view.js` 生成星球地貌、地标、道路和飞船；`src/music.js` 编排动态配乐。新增测试覆盖山路闭合、高度和间距、高速核心／加速带接触、FOV 随速度扩大，以及星球配乐切换与声音资源回收。
