# 月面速递 · Lunar Courier

当前版本 **1.37.0**。游戏首页的「更新公告」展示本版变更与历史公告，完整记录见 [CHANGELOG.md](CHANGELOG.md)。公告顶部的关闭按钮在滚动历史时保持可见，关闭后回到原入口。

本版增加精细操纵：按住 Shift 临时缩小三轴幅度，或点按顶部按钮保持，幅度可设为 10%–80%。补齐滚转与方向舵的持续配平键，支持三轴微调；手机可一指推杆、另一指切换精细模式，平板宽度的顶部按钮保持单行。1.36.1 公告原文移入历史。

支持手机横竖屏双拇指驾驶：滑动转向、松手回正，点按巡航后持续加速，再配合冲刺与跃升。操作指南可切换左右手布局、按键转向、按住加速，并调节 50%–150% 转向灵敏度。手机 HUD 和竖屏跟随镜头减少道路遮挡，触屏设备默认均衡画质；设置仅保留在当前页面。

背景音乐为原创程序合成配乐，包含和声铺底、旋律琶音、低音线及飞行鼓组。58 颗星球各有调性与节奏，实际速度越快，打击乐与旋律层越密；新星球分别使用大小调与正弦／三角波旋律，基地使用舒缓编排。首次主动操作后启用。操作指南提供音乐、引擎／音效独立音量与总静音；暂停及结算界面也可进入设置。暂停或离开页面会停止声音，继续飞行后恢复；声音偏好仅保留在当前页面。

陨石、碰撞、漏门、失速与自动化退出警告期间，配乐短暂降至所选音量的 40%，随后平滑恢复，音量滑块数值不变。暂停、总静音、切出页面或关闭音效时清理临时压低状态；音乐与音效仍可独立调节。

一个可直接在浏览器游玩的 3D 星际悬浮艇游戏。在 57 颗架空星球与地球的盘山公路上高速交付，穿过 6 座导航门、收集能量核心，再限时返航。58 条独立航线与四十款悬浮艇全部开放。

山路包含连环山脊、环形天坑、双峰回旋、海岸长弯、高原阶梯、花瓣回湾、锯齿群峰、洲际连峰、环陆群湾、通天山桥、峡湾悬廊、星冠盘山、叠湾天路、云环叠岭和双脊悬桥十五类。25 条短程路线为 7.0–14.8 公里；33 条长途路线为 20–240 公里，每颗星球都有独立地标。机库支持组合搜索星球、航线、路线类型，并与分类筛选叠加使用。实际三维长度与仪表里程一致；速度越快，镜头视野越宽，速度线、尾焰与配乐同步变化。

险情与临近导航门提示按当前速度、松开转向后的侧移惯性估计；障碍风险还会考虑跃升高度和下落过程。继续转向、加速或制动会改变后续路线。发生惯性侧滑时，提示卡提醒横移修正；同时接近多处危险时优先显示预计最先接触的一处。

即使满级引擎的「新星」始终保持 492 m/s 冲刺，原有 96 公里及以上的长途赛道也需要至少 195 秒，不含倒计时或暂停。原有 96–123 公里长途驾驶约需 5–14 分钟，连续加速图约需 3–5 分钟，机库会按所选飞船估算用时。这些路线的任务时限为 845–1070 秒，需交付 24–36 枚核心。幽灵录像按任务时长调整采样间隔，保留完整航程和过门时刻。

六条 150–240 公里山桥长线的最低驾驶时间为 305–488 秒，普通巡航约需 11–26 分钟，机库按所选飞船估算用时。任务时限为 1295–2045 秒，核心目标为 48–54 枚。这六张地图平面跨度均超过 14 公里、高差超过 1700 米；每条分布 13–20 座跨谷桥，具有桥塔、主缆、吊索、侧梁、桥墩与灯标，桥上保留普通驾驶与避障规则。

按 Esc / P 或顶部「设置」暂停，展开「操作与键位」，可切换经典飞行和 WASD 升降预设、反向升降，并恢复默认操作设置。WASD 标准方向用 W 前推低头、S 后拉抬头，↑ / ↓ 增减油门；经典飞行保持 W / S 油门、↓ / ↑ 拉升 / 俯冲。默认 A / D 滚转、Q / E 左右偏航，可独立切换为 A / D 偏航、Q / E 滚转；← / → 始终滚转。反向设置同时作用于键盘和触屏，指南、页脚与起飞提示同步更新。操作设置对所有机型共用，仅保留在本次飞机模式。

俯仰、滚转、方向舵灵敏度分别可设为 **20%–200%**，同时作用于键盘与触屏，最终输入以 100% 封顶，较高灵敏度让摇杆提早打满。操纵渐进时间 **0–800 ms**、松手回中时间 **0–600 ms**，默认分别为 160 / 100 ms，表示三轴满幅输入到位与回中的用时，部分行程按比例缩短；设为 0 直接响应，反向输入先回中再向另一侧移动，按固定物理步更新。触屏中心死区 **0%–25%**，过滤小幅误触后连续衔接到满杆；响应曲线 **1×–3×**，1× 为线性，越高越便于中间行程的小幅修正，满杆仍保留最大输入。键盘油门变化为每秒 **5%–100%**，松手保持目标油门；快捷按钮直接设定目标，发动机仍按机型与调校逐步跟随。刹车、自动驾驶手动接管不等待渐进输入。左右舵同时按住会抵消并回中；暂停、切换操作设置或离开页面立即清空输入，聚焦编辑框会释放键盘操纵，保留触屏同时推杆和调油门；方向舵和制动按钮也支持聚焦后按住空格 / Enter。

精细操纵在灵敏度之后将三轴输入缩小到所选幅度，范围 **10%–80%**、默认 **40%**，适合进近与小幅修正。按住任一 Shift 临时启用，顶部按钮可保持开启；松开 Shift 后仍遵守按钮选择。油门、刹车、配平和自动驾驶的原始手动接管意图不受幅度限制，Shift 本身不接管。暂停保留按钮选择，返回机库、重新起飞或恢复默认操作设置关闭保持。三轴配平键按设定配平速率持续调整，相反键抵消，松开保持当前位置；T 将三轴配平归零。

「飞行物理与机动」提供稳定飞行与自由机动：前者将操纵量转成目标姿态，适合起降；后者按机体轴持续旋转，可滚转、倒飞和筋斗，默认关闭松手回正。速率设置 100% 且满杆时，A380 俯仰约 13°/s、滚转 28°/s，Su-30 分别约 49°/s、103°/s；低速会削弱操纵能力。先爬升再练习机动，倒飞与急转会损失高度，爬升消耗速度。

机库与暂停设置提供 **21 项参数**，均有滑杆和数字框，步进 1%。数值相对当前机型的标准值；数字离开输入框时取整并校准范围，空值恢复当前有效值。

「恢复标准」「灵活机动」「极速动力」「轻松巡航」替换本机整套参数；手动调整后显示为自定义。每架飞机分别保留本次飞机模式内的调校，退出后重置。自由机动时辅助角度输入禁用。性能卡实时显示发动机稳定后的满推力加速、起飞、失速、着陆、速度上限、临界迎角与载荷上限参考；低速参考计入当前襟翼与坡度，并提示零推力或起飞参考超过速度上限的组合。暂停调校保持位置、速度、发动机输出与姿态，恢复后按新参数运动。

迎角根据机头、机翼倾斜和实际升降航迹估计，超过临界角时逐渐损失升力、增加阻力并减弱操纵；高于低速参考也会失速。先减小拉杆和迎角、收减速板并保留恢复高度，避免一味加大拉杆。拉升载荷越大，诱导阻力越高；空速按实际升降航迹交换重力势能，抬头不会瞬间改变水平速度。HUD 与座舱显示迎角和机翼法向载荷，G 以当前重力为基准，地面显示 0。默认战机、教练机、客机与运输机使用不同迎角和载荷范围，均为游戏参数，未使用真实机型气动数据。

A380 驾驶舱提供四屏仪表、四油门手柄与副驾驶座，Su-30 提供三屏仪表、双油门手柄和座舱框架。空速、高度、姿态、升降率、航向与起落架状态实时更新，操纵杆和手柄随输入变化。这些内饰为游戏原创简化建模。驾驶舱与远处机场分别绘制，保持近处手柄和远处海岸的深度精度。

公务机与运输机使用较窄的四屏双座驾驶舱，配双油门；教练机提供三屏与单油门、方向盘式操纵，三角翼战机使用三屏与单油门、操纵杆。发动机仪表按各机型的发动机数量绘制，并显示实际输出。

十二机型驾驶舱均提供二十二按钮：下方两排 **ENG / PARK / REV / A/BRK / TOGA / TRIM 0**、**AP LVL / AP HOLD / A/THR / GEAR / FLAP / BRK**，上方两排 **BAT / GEN / APU / AVIONICS / Y/DAMP / SPLR ARM**、**NAV / BEACON / LAND / TAXI**。绿灯为激活，琥珀灯为待命、收放或启动中，灰灯为暂不可用；没有 APU 或反推的机型对应按钮不可用。操纵杆显示配平、偏航阻尼和自动驾驶后的指令。开关共用文字图集和实例化模型，两个绘制批次；状态变化时合并一次颜色上传。确认音和自动脱开双音遵守音效音量、暂停与静音。

NAV 控制左红右绿和尾部白灯，BEACON 控制红色双闪；LAND 为前向着陆照明，TAXI 为较宽的近距滑行照明，收轮时自动熄灭。全部需要母线供电，关闭航电不影响外灯；断电保留开关选择，恢复供电后重新点亮。灯具使用一个实例批次，照明不投射阴影，暂停冻结闪烁；系统面板说明可展开查看。

BAT 电池、GEN 发电机与 APU 辅助动力分别供电；航电同时需要电源与 AVIONICS 接通。断电或关航电会熄灭座舱屏幕、退出 AP / A/THR，发动机继续运行，外部 HUD 与系统面板保留操作入口。客机地面重启：**BAT → APU → 等待约 5 秒至 READY → ENG → 确认 GEN 供电 → 关闭 APU**。三款客机与 B-62 有 APU，其余机型使用电池启动；空中允许有电时重新点火。默认已启动，无需手动执行启动流程。电池不消耗电量，未模拟真实机型完整电气与引气系统。

Y/DAMP 在有航电且离地时通过方向舵抑制侧滑，满打手动方向舵可接管；关航电时停止作用，开关保留。SPLR ARM 在接地、油门低于 15% 且有供电时自动展开扰流板，也支持接地后收油；TOGA 复飞同时解除预位并收起减速板。预位和 APU 状态显示在第四块客机仪表与系统面板中。

按 I 或顶部「系统」打开实时面板，可操作发动机、驻车、反推、自动刹车、复飞、自动油门、姿态自动驾驶与三轴配平；打开时清除按住的操纵输入，面板不会暂停飞行。手机通过可滚动面板操作全部系统，按钮至少 44px 高，关闭入口保持可见。Esc 先关闭面板，再按暂停。需要冻结飞行调参时，按 Esc / P 打开暂停设置中的「座舱系统、配平与自动驾驶」。

关闭发动机后出力逐步降至零、飞机继续滑翔；满足启动条件后重新开启按发动机响应恢复，保留目标油门。驻车制动只在地面低于 **3.6 km/h** 时接通，可在加推时保持静止，起飞前按 N 释放。切换跑道方向和跑道起飞沿用预飞的系统开关、APU 进度、油门与配平状态；返回机库重置，直接空中试飞使用已启动、无驻车与反推、自动刹车关闭、配平归零的状态。

机翼调平只控制滚转，俯仰仍手动；航向 / 高度保持捕获接通时的航向和高度，之后可修改目标，航向按最短方向转弯。目标高度以米计、不能低于零。自动驾驶仅在稳定模式、发动机开启、足够空速和正常姿态下接通；接通空速参考为当前失速参考的 **115%**，同时计入襟翼、坡度和物理调校，运行中低于 **110%** 时自动退出。大迎角时拒绝接通或退出，并显示卸载提示。达到手动接管阈值、接地、关机、姿态超限或进入自由机动时也会退出。油门可手动或独立使用 A/THR 保速；自动化不避让地形或建筑，也不自动着陆。

仪表旁持续显示姿态模式与 A/T，保速时显示目标空速，单独 AP 保持时显示目标航向和高度；点按「接管」或按 Backspace 同时退出 AP 与 A/THR，按钮收起后焦点回到飞行界面。输入框内 Backspace 继续删除内容。系统面板显示具体阻止条件和动态接通参考空速，不可用时禁用接通；已激活的模式始终可关闭。重新接通会更新通知，飞行结束清除自动化激活状态，暂停保留当前模式。

**A/THR** 接通时捕获当前空速，随后可用 km/h 设置目标。目标范围为当前失速参考的 **130%** 至速度上限，计入襟翼、坡度和调校；低于失速参考的 **110%**、迎角过大、关闭发动机、零推力或接地时退出。键盘增减油门、滑杆、快捷油门与制动均可接管；姿态手动操纵只按 AP 的阈值退出 AP。单独关闭 AP 保留 A/THR，Backspace 退出两者。推力不足或陡峭航迹时无法保证目标速度。

**REV** 仅 A380、B-62 与 C-24 接地且发动机开启时可展开，油门调节反推，发动机仍保留渐进响应；不能倒车或带反推起飞，按 M 收起后恢复前向推力。**A/BRK** 可在空中选择低 / 高档待命，着陆后收油或使用反推时自动轮刹；手动刹车取消待命，起飞滑跑不触发。**TOGA** 一键设置全前向油门，收起反推与减速板、取消 AP / A/THR / A/BRK；不瞬移或立刻改变发动机出力，起落架、襟翼和驻车保持原位，需自行确认。

| 座舱系统参数 | 范围 | 作用 |
| --- | --- | --- |
| 配平最大作用量 | 5%–40% | 三轴配平叠加到手动操纵的最大量 |
| 键盘配平速度 | 1%–30%/秒 | 按住 [ / ] 时俯仰配平的变化速度 |
| 自动驾驶响应 | 25%–200% | 航向与高度修正的响应 |
| 自动驾驶最大坡度 | 5°–35° | 航向保持的目标坡度上限，仍受本机辅助角度限制 |
| 目标升降率上限 | 1–15 m/s | 高度保持的目标升降速度上限，实际瞬态受飞行物理影响 |
| 手动接管阈值 | 5%–60% | 任一轴在死区、曲线处理后且灵敏度缩放前达到此值时退出，满输入始终可接管 |

三轴配平滑杆范围为 −100%–100%，实际影响由配平最大作用量决定；T 同时归零三轴。AP 的操纵接管判断不包含油门，反向操纵抵消和摇杆死区继续生效；实际接管后的操纵力度仍按所选灵敏度。十项系统参数对所有机型共用，换机保留，退出飞机模式后重置，不保存运行状态。

三处机场在机库顶部选择：蓝湾海岸跑道 4,000 × 60 m、海拔 0 m；云岭高原 3,600 × 45 m、海拔 820 m；赤沙盆地 4,600 × 60 m、海拔 160 m。两侧各 15 m 道肩，均为游戏场址，不代表真实机场认证标准。高原航站区位于东侧，沙漠额外设机库；地形、设施碰撞、六环训练与返航导航同步所选机场。场址切换保留当前飞机与预飞系统，飞行中需先返回机库才能切换。

机库可选跑道 36 向北或 18 向南起飞，剩余跑道距离随飞行更新。默认调校且收起襟翼时，A380 达到约 281 km/h、Su-30 达到约 234 km/h 后拉升；使用起飞襟翼可降低参考速度。离地后按 G 收轮，客机收放约七秒，其余约四秒，阻力跟随实际伸出比例；暂停冻结收放。着陆前提前放轮并等待绿色锁定，收放中座舱为琥珀指示，滑行灯等待锁定才点亮。轮胎接地点与可见跑道、滑行道和停机坪高度同步。稳定模式默认松手辅助回正；倾斜转弯会损失升力，低空留出净空。速度过低会失速并下坠，可降低机头、收起减速板并加大油门恢复。

襟翼有收起、起飞、着陆三档，改变低速升力和阻力，仪表的起飞与失速速度同步变化。A380 展开上限为 486 km/h，Su-30 为 594 km/h；超过上限 18 km/h 后自动收起并提示。减速板可持续展开以便进近减速，起飞前需收起；地面停车仍要收油并按住制动，减速板不代替轮刹。驾驶舱屏幕同步显示襟翼档位和减速板状态。

顶部镜头按钮打开六机位面板：追随、近距、驾驶舱、机首、左翼与俯视。C 循环机位，V 进入驾驶舱或返回上次外部机位。L 锁定当前外部观察方位和水平地平线，镜头位置仍随飞机移动；切换机位、调整镜头参数、重新起飞或按 R 回正解除锁定。R 同时清除环绕角度与舱内侧看。面板可点关闭按钮、面板外或 Esc 关闭；面板打开时第一次 Esc 只关闭面板，再次按下才暂停。

「镜头与视野」提供驾驶舱视场角 **50°–100°**、外部视场角 **40°–100°**、外部距离 **50%–300%**、高度 **50%–200%**、环绕角度 **−180°–180°**、跟随响应 **1–15/秒**、舱内观察幅度 **30°–120°**、转头响应 **2–20/秒**、速度扩角开关和扩角幅度 **0°–30°**，支持恢复默认镜头参数。响应越高，镜头跟随或转头越快；驾驶舱视场角同步作用于舱内与远景。外部机位始终保留机身和地面净空，实际最近距离受机型大小限制；未锁定时自由机动镜头随完整姿态旋转。设置仅作用于本次飞机模式。

「座椅与实体仪表面板」提供座椅高低 **−15–30 cm**、前后 **−20–35 cm**、默认视线俯仰偏移 **±15°**、面板缩放 **80%–110%**、高低 **−20–10 cm**、前后 **−20–25 cm**。座椅与视线改变实际视点，面板调节同步改变屏幕、按钮、标签和起落架手柄，点按位置随之更新。外部机位不受影响；可独立恢复默认，设置仅保留在本次飞机模式。

「远景视距与地景 LOD」默认 **100 km**，可调 **30–160 km**；雾与海面同步覆盖。地面默认为低模，可选均衡、精细，细节距离 **1.5–12 km**，越小越早简化。42 块地形各有三档网格，远处机场使用建筑轮廓；各档共用边缘顶点与法线，切换带回滞，减少裂缝与反复切换。地景设置不影响飞机、座舱或物理碰撞，视距调节不扩大岛屿范围。

转弯时实际水平航迹逐渐跟随机头，保留惯性；横向响应越低越明显。侧滑会损失速度，HUD 显示侧滑角，驾驶舱姿态屏的侧滑球辅助判断是否对齐。六座训练环按顺序激活，自由飞行没有时间限制。降落前放轮、减速，将机头与实际航迹共同对齐跑道并保持机翼平稳；默认调校时 A380 接地速度不高于 378 km/h、下降率不低于 −7 m/s，Su-30 分别为 486 km/h、−10 m/s。自定义后以性能卡的着陆速度上限为准。落地后油门归零、制动停下完成返航。触水、建筑碰撞、过重着陆和高速冲出跑道会结束飞行，可返回飞机机库重试。

点击飞行仪表上的「返航 ↗」可随时切换机场导航，显示返回机场的转向与距离；不需要先完成训练环。小屏设备会收起姿态圆盘，为飞机和操纵杆留出空间。480–559 px 窄横屏使用紧凑油门与导航布局；横屏展开镜头、系统或暂停面板时，顶部设置与返回基地仍可点击。

暂停面板提供 **0.5× / 0.75× / 1× / 1.25× / 1.75× / 2×** 渲染比例上限（受设备像素比限制）、**30 / 45 / 60 / 90 / 120 FPS** 或跟随屏幕刷新率（默认 60 FPS）、**5 / 10 / 20 Hz** 舱内仪表刷新（默认 10 Hz），以及背景音乐、引擎与音效音量。帧率选项是上限，实际帧率受设备与屏幕限制；限帧保留累计动画时间，物理和输入继续独立更新，暂停无变化时不重复绘制，外部机位及航电关闭、母线断电时不上传舱内仪表纹理，恢复供电后立即刷新。机库内可查看模型署名。切出页面或旋转屏幕会暂停；返回基地恢复原有山路游戏。原场景在飞机模式内停止渲染，飞机模型、GLB 加载器与样式在进入时加载。设置不写入持久存储。

A380 使用用户提供的 CC BY 4.0 模型；其余十一款为本项目原创简化 GLB，采用 CC0。来源、授权与生成方法见 [模型署名](assets/aircraft/README.md)。

## 漂移与转弯设置

从「任务机库 → 驾驶手感与转弯半径」或操作指南进入。均衡、精准、漂移三种预设均支持进一步细调，每项提供滑杆和精确数值输入。

| 参数 | 范围 / 步进 | 作用 |
| --- | --- | --- |
| 转弯半径系数 | 0.40–2.50× / 0.01 | 越小横向起弯越紧，越大变线弧线越平缓 |
| 横移幅度 | 0.40–1.60× / 0.01 | 持续转向时的最大横移速度 |
| 松手抓地 | 4–24/s / 0.25 | 越大松手后越快收漂 |
| 反打力度 | 1–3× / 0.05 | 反向转向时消除原来侧滑的速度 |
| 制动抓地 | 1–4× / 0.05 | 制动时的横向收漂力度，保留转向能力 |
| 高速稳定 | 0–60% / 1% | 随速度渐进收小横移幅度，减少高速过量转向 |
| 小幅转向曲线 | 1–2.50× / 0.05 | 越大触屏滑动中心越细腻，满幅和键盘左右键不受曲线削减 |

道路航向仍自动跟随；半径系数描述横向变线手感，不代表道路半径或固定米数。默认均衡手感的松手残余侧移比旧版减少约 24%；反打先消除原方向侧滑，再平顺进入新方向，制动同时降低前进与侧移速度。

修改后点击「应用驾驶设置」；未改动时按钮禁用。「撤销未应用更改」返回上次应用的配置，「恢复均衡默认」只调整草稿，仍需应用。每项显示范围和步进，数值输入在离开输入框时校准，空值恢复最近有效值。在基地为下次出发应用；飞行中保存将在重飞或下一站生效，当前航程保持原设置。未应用的草稿不影响驾驶；重飞、换艇与换图沿用已保存配置，刷新恢复默认。个人纪录、幽灵及赛事电脑航迹按驾驶配置分别计算，电脑使用相同的物理参数。导航门、挑战环和危险提示同步使用所选抓地参数预判惯性。

## 道路 NPC 交通

打开「任务机库 → 道路 NPC 交通」调整车流，点击「应用交通设置」或「确认飞行配置」生效。

修改后折叠栏显示「待应用」，当前车流保持已应用配置；可点击「撤销未应用更改」恢复。应用与撤销后聚焦状态文字。比例归零会取消车型；滑杆禁用时聚焦对应复选框，可按空格重新勾选或取消。

- **四种车型**：轿车、厢式车、重型货车、半挂卡车。默认比例为 15% / 15% / 30% / 40%，重型货车与半挂合计 70%。
- **密度与比例自选**：每公里 0–12 辆；勾选允许出现的车型，拖动比例时其余已选车型自动分配剩余份额，合计 100%。仅选一种车型时自动设为 100%；全部取消或密度设为 0 时无车。短路线的实际辆数按整数配额分配。
- **沿路行驶与避让**：车辆以 24 m/s（约 86 km/h）同向行驶，保持车距，提前向路肩平滑绕过路侧岩石，车身完全通过后再回到车道。转向时模型朝向与碰撞范围同步；驾驶提示和电脑领航员按预计相遇时的车道判断。与车辆碰撞会受损，护盾可抵挡，可横移或跃升避让。地球与纯加速无障碍航线始终不生成车辆。
- **配置与成绩**：设置只保留在当前页面，重飞、换艇与换图沿用，刷新恢复默认。不同车流配置的个人纪录与赛事电脑航迹分别计算；电脑与玩家使用相同车流配置。

四种车型各有独立轮廓、轮胎、车窗、前后灯与货厢细节。渲染仅更新附近车辆，每种车型使用固定容量的实例池；240 公里路线也不会同时绘制整条路线的车流。暂停冻结交通，重飞重置车辆位置。

## 道具拉力与马拉松

机库选择「道具挑战」可找到十四条路线，其中四条新增航线也可按「进阶拉力」筛选。首批四条路线中，飞瀑穿峡、风帆天路、光穹回廊各长 **20 km**，山海马拉松长 **50 km**。20 公里路线有 6 枚道具、4 个挑战环；马拉松有 15 枚道具、10 个挑战环和 5 座跨谷桥。20 公里时限 212 秒，50 公里时限 462 秒；实际用时取决于飞船、冲刺和驾驶表现，不人为延缓高速航程。

- **蓝色护盾**：拾取后 12 秒内抵挡一次碰撞，保护装甲、速度和连收，被撞后消耗。
- **紫色磁吸**：8 秒内将核心吸附范围提升至至少 9 米；必须低空收集，不改变永久改装。
- **绿色维修**：恢复 35 装甲、30 能量，不超过上限。
- **金色极速环**：低于 2.3 米、达到当前巡航速度的 90%，从环中心左右 3.5 米内穿过，基础奖励 200 分。
- **紫色跃升环**：按 F 或触屏跃升，在 2.8–6.2 米高度穿过，横向容差 3.5 米，基础奖励 350 分。

仪表显示前方补给数量、下一份种类与距离、剩余挑战环，补给全部驶过后会明确提示。护盾、磁吸和超频各有倒计时条，最后三秒转为暖色；极速环和精准环提示当前还缺多少速度或是否需要降低高度，精准环另标注横向容差。

临近三类挑战环时，方向提示按当前速度和松开转向后的惯性预估穿环横向位置；当前居中但将滑出时会提醒反向修正，预计滑入时提示松开转向。横向对准不代表高度或速度已经达标；加速、制动和继续转向会改变预测结果。危险和临近导航门继续优先显示。

每次命中挑战环恢复 12 能量；连续命中每次额外增加 50 分，上限额外 200 分。漏环、实际受损或漏过导航门中断连锁。成功交付且最长连锁达到 3 次可获「环线达人」。道具自动拾取，暂停冻结剩余效果，重飞重新生成；回退无法重复领取奖励。三种模式均保留核心与六座导航门的交付要求，可选挑战不影响晋级，结算显示道具、命中、连锁与护盾抵挡次数。

## 陨石与低重力航段

常规航线包含动态环境。短程的宁静天路有 2 处陨石落点、1 段低重力区；进阶山路有 3 处落点、2 段低重力区；极限山路有 4 处落点、2 段低重力区。普通长途航线沿途重复分布环境航段；三张特殊地图采用各自的规则。

- **陨石落点**：红圈提前 2.6 秒预警，收缩圆环与仪表倒计时提示撞击时间。落地后的 1 秒内会产生冲击波，低空接触造成 22 点伤害。可横向绕开，也可把握时机跃升；成功在空中越过冲击波获得 180 分。灰色落点与撞击退去后的余辉不会伤害艇体。
- **低重力区**：紫色边线、入口光柱和雷达上的紫色航段标出范围。区内下落加速度由 17 降为 8 m/s²，普通跃升可以达到约 7.6 米，腾空时间更长。腾空离开区域获得 200 分，但高空仍无法收集核心。
- 每处环境技巧奖励仅计一次；须在整个冲击波接触期间保持足够高度，脱离危险后才结算规避奖励，落入冲击波或漏门回退不会获得奖励。低重力滑翔按穿越出口瞬间的高度判定。成功交付可获得「踏星而行」「引力旅人」奖章，结算同时展示冲击波规避和滑翔次数。

陨石按实际飞行用时循环，倒计时与暂停不推进环境；重飞会重置时钟和奖励记录。个人幽灵与电脑对手采用相同的时间规则，电脑会评估连续障碍、巡逻机未来位置和落点的危险时间，再选择航向或跃升。

跃升、下落采用按重力区边界分段的抛物线计算，不同时间步长保持相同的垂直轨迹，高速一帧跨过整段低重力区也不会漏算。碰撞、加速带、穿环与危险预判共用轨迹；跃升环建议结合前方重力计算，继续加速或制动仍会改变到达时机。正常重力下跃升最高约 3.6 米、腾空约 1.29 秒；全程低重力时约 7.6 米、2.75 秒。

腾空接近跃升环时，提示按当前速度、升降速度和前方重力预估穿环高度，区分高度达标、不足和偏高；回落到环下方时不再继续提示对准。加速、制动或变线会改变预测。

仪表区分上升、顶点与回落。落地时模型随实际着地速度轻微下沉回弹，俯仰平滑恢复，提示音也随力度变化；缓冲只影响模型表现。暂停冻结缓冲与姿态，重飞或漏门回退清除落地状态。

## 运行

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，默认是 http://localhost:5173 。需要支持 WebGL 2 的浏览器并开启硬件加速。触屏设备可使用同一局域网下的 Network 地址访问。

## 操作

| 操作 | 按键 |
| --- | --- |
| 加速 | 按住 W / ↑ |
| 巡航油门 | C / 顶部巡航按钮，保持普通加速 |
| 左右避障 | A、D / ←、→ |
| 制动 | S / ↓ |
| 冲刺 | 空格，松开后自动充能 |
| 跃升 | F，消耗 18 能量，冷却 1.6 秒 |
| 暂停 / 继续 | Esc / P |
| 开始 | Enter / 点击开始飞行 |

屏幕驾驶按钮支持 Tab 聚焦，再用空格或 Enter 操作；持续动作需按住，跃升按一次触发。跃升按钮在空中、冷却中或能量不足时标记为不可用。

浏览器的 Ctrl/Cmd/Alt 组合快捷键与输入法输入不会触发驾驶或启用声音；普通驾驶键与 Shift+Tab 焦点循环保持可用。

结算先显示并聚焦任务结果标题；按 Enter 重飞或继续下一站，用 Tab / Shift+Tab 访问分段报告、补给升级和操作按钮。

巡航只保持油门，不负责转向、过门或躲避障碍，也不自动使用冲刺。制动会立即关闭巡航；暂停、离开页面、受撞、漏门、结束或重飞后均需重新开启。三种模式使用相同的巡航规则，速度与冲刺能量消耗保持原有数值。

航向自动跟随环线，玩家负责速度和横向移动。蓝色核心增加分数、修复艇体并补充冲刺能量。岩石及航道边缘会损伤艇体；漏过导航门会退回门前并扣除 4 秒。切换标签页自动暂停。支持触屏、音效开关和五档性能参数；帧率偏低时会自动启用流畅模式，也可在操作指南中手动调整渲染比例、动态阴影与环境泛光。

绿色加速带提供 1.8 秒免费加速和能量补充，驱动期间按住冲刺也会自动充能，跃升仍正常耗能；加速带效果结束后恢复手动冲刺的能量消耗。跃升可以越过岩石与移动巡逻机，但高空无法收集核心。须在整个接触期间保持足够高度，通过障碍后才获得空中避障奖励；中途落入障碍或漏门回退不会获奖。跳跃需要松开按键后才能再次触发。

连续收集每 3 枚核心提高一次得分倍率，最高 3 倍；漏收或碰撞会中断连收。普通过门 300 分，高速从门中央穿过得 500 分，空中避障得 120 分。成功返航另有时间和艇体奖励。

结算展示最高连收、精准过门、空中避障与任务奖章；无伤、快速返航、收集率和驾驶表现决定评级。每个航线与飞船组合的最佳得分、最快用时只保留在当前页面内存，刷新即清空。

## 幽灵挑战

自由速递模式下，首次成功返航后，再次驾驶同一款飞船挑战同一航线，会出现紫色个人幽灵，重现最快成功航程。幽灵不会碰撞或收集核心；只有更快的成功航程才会替换它，最高得分单独统计。可在任务机库或操作指南中关闭「航迹投影」，分段成绩仍会比较。

飞行仪表显示与幽灵的当前距离，以及最近一座导航门的累计时间差。每次过门另显示本区段的时间差；结算中的“分段飞行报告”可展开查看全部 6 座导航门与返航段，负值表示比起飞前的最快纪录更快。首航与失败航程也能查看已完成区段。

比较采用实际飞行用时：倒计时、暂停不计入；漏门会增加重新驶向导航门的飞行时间，并另外扣除剩余时限 4 秒。幽灵同步暂停，并按原航程重现漏门回退。轨迹只保存在当前页面内，刷新清空。

导航提示显示下一座门的对准方向；前方有可能相撞的岩石或巡逻机时，会提示距离和避让方式。巡逻机预警按当前速度估计相遇位置，仍需要观察实际航道并主动驾驶。

## GitHub Pages

构建采用相对资源路径，同一份 `dist/` 可用于域名根目录或仓库子目录。GitHub Pages 需发布构建后的文件，直接从 `main` 根目录发布源码无法运行游戏。

1. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
2. 将包含工作流的提交推送至 `main`，会自动触发部署；之后也可在 **Actions → Verify and deploy Pages → Run workflow** 选择 `main` 手动运行。
3. 工作流使用 Node.js 22 执行 `npm ci`、测试和构建，通过后仅上传 `dist/` 并部署。部署成功后，从工作流的 `github-pages` 环境链接进入游戏。

本仓库的 Pages 地址为 https://hanazar-games.github.io/GPT6-Max-Test-Project-1/ 。Pull request 只运行测试与构建，不发布网站；手动选择非 `main` 分支也不会部署。`dist/` 不提交到 Git。

## 代码结构

技术：Three.js、Vite、原生 JavaScript、Web Audio。`src/missions.js` 定义任务、飞船和航线；`src/game.js` 是独立于渲染的固定步长模拟；`src/ghost.js` 管理有界轨迹采样、时间插值、分段比较和会话纪录；`src/pilots.js` 模拟电脑领航员，`src/cup.js` 管理赛事晋级、积分、实时排名和奖杯。测试覆盖驾驶规则、幽灵、赛事结算与同分排序，以及全部 2320 种任务/飞船组合和 6960 条电脑航程的连续通关。切换任务会释放旧场景资源，并复用渲染器；多艘投影共享几何体，使用独立材质。

`src/expedition.js` 管理远征委托、补给结算和晋级；`src/upgrades.js` 计算独立飞船配置；`src/expedition-ui.js` 展示委托与补给站。远征测试覆盖奖励去重、购买限制、失败重试、实际性能与吸附判定，以及各款飞船在 58 条航线上采用单项满级或全部满级升级的连续通关。

`src/environment.js` 定义环境时间表、重力、轨迹预测与陨石碰撞；`src/environment-view.js` 生成对应的三维场景。环境测试覆盖撞击时间边界、快速穿越与横向移动、暂停冻结、奖励去重、重试重置，以及连续障碍的电脑避让。

`src/route.js` 负责实际长度的山路、路面倾斜与随速度变化的镜头视野；`src/planet-view.js`、`src/landmarks.js` 和 `src/craft-view.js` 生成星球地貌、地标、道路和飞船；`src/bridges.js` 定义跨谷桥段，`src/bridge-view.js` 生成桥梁结构；`src/music.js` 编排动态配乐，`src/terrain-sampler.js` 负责长赛道的地形空间查询。测试覆盖山路闭合、高差、桥梁与地形净空、最低驾驶时长、资源预算、高速接触判定、FOV，以及星球配乐切换与声音资源回收。

`src/route-rewards.js` 定义道具、挑战布局与导航；`src/reward-view.js` 渲染道具和光环。测试覆盖高速拾取、一次护盾、磁吸高度限制、资源上限、暂停重飞、穿环插值、连锁与回退防刷，电池补能、超频解除、精准环容差，以及模型显隐和资源释放。
